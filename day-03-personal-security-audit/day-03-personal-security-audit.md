# Day 3 – Personal Security Audit

Today was about understanding my own digital security and learning how to identify possible risks in my online presence.

A few things I explored today:

- **Personal Security Audit:** Understanding how to check accounts, devices and networks for possible security issues.
- **OSINT:** Learning how publicly available information can help investigate a digital footprint.
- **Data Breaches:** Exploring how personal information can get exposed through data breaches.
- **Credential Exposure:** Understanding the risks of exposed passwords and stealer logs.
- **Account Security:** Learning about 2FA, active sessions, password reuse and account recovery.
- **Risk Assessment:** Understanding how to classify security findings as Critical, High, Medium and Low.
- **Remediation:** Learning how to fix identified security issues and improve account protection.

### Tools Explored
- Have I Been Pwned
- Epieos

### Practical Work
Performed a basic personal security audit, reviewed account security, explored breach records and prepared an audit report.

### My Reflection
Today's activity made me realise that personal security involves more than just having a strong password. Checking account activity, reviewing permissions and understanding data exposure are also important.
Finding 11 breach records was a useful reminder to regularly monitor my digital presence.
